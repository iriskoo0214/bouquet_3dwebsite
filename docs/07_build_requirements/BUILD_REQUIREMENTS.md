# Build Requirements

## 기술 스택
| 항목 | 값 |
|---|---|
| 번들러 | Vite 6 |
| 언어 | HTML / CSS / Vanilla JS |
| 3D | @google/model-viewer 4 |
| 폰트 | Pretendard (CDN) |
| 모델 | `public/models/model.glb` (현재 1개) |
| 배포 | GitHub → Vercel (Build: `npm run build`, Output: `dist`) |

## 기능 요구사항
| 기능 | 조건 |
|---|---|
| 회전 | 드래그 360°, 시점 버튼 앞 / 뒤 / 위 / 아래 |
| HAND | 손에 든 모습 토글 — **손 모델 미준비**, 지금은 안내 토스트만 |
| Undo/Redo | 옵션 선택 이력 스택 |
| 모양 | 4종(라운드·내추럴·캐스케이드·크레센트), 바꾸면 송이 수·가격 재계산 |
| 크기 | 스몰 10~15 · 미디엄 16~25 · 라지 26+ 송이 |
| 색 & 꽃 | 테마 컬러 → 해당 계열 꽃만 표시, 메인·서브 선택 |
| 견적 | 제작·포장비 130,000 + 그린·필러(크기별) + 메인 평균 단가 × 메인 송이 + 서브 평균 단가 × 서브 송이 + 모양 추가금 (`src/data/flowers.json` pricing). 송이 수는 크기 범위의 가운데(스몰 12 = 메인 5 + 서브 7 · 미디엄 20 = 8 + 12 · 라지 28 = 11 + 17). 예: 라운드·스몰·장미 줄리엣·스프레이 장미 = 196,000원 |
| 조명 | 자연광 · 실내광 · 어두운 조명 → 캔버스 배경 사진(Figma 배경1·2·3) 교체 + 3D exposure 변경 |
| 샘플 드레스 | 롱 · 미디 · 숏 |
| 이미지 저장 | model-viewer `toBlob()`으로 PNG + 구성·가격 텍스트 |
| 플로리스트 문의 | 전송 완료 상태만 표시 (실제 전송 없음) |

## 3D 표현 방식 (결정: 2026-11-18)
**모양별 .glb 모델을 따로 준비한다.** 모양이 이 서비스의 첫 번째 선택이라, 실제 형태가 바뀌어 보여야 하기 때문이다.
- 모양 4종 → 모델 4개 (`public/models/shapes/<id>.glb`)
- 크기(스몰·미디엄·라지)는 화각(field of view)으로 표현한다 — 모델마다 꼭 맞는 화각 × 1.6 / 1.35 / 1.12 (model-viewer는 줌을 화각으로 처리해서 scale·거리로는 크기 차이가 보이지 않았다)
- 색은 모델의 꽃 material 색을 바꿔 표현한다 (material 이름 규칙은 `MODEL_SPEC.md`)
- 모델이 아직 없는 모양은 내추럴 모델(`natural.glb`)로 대체하고 "준비 중" 표시를 한다
- 모델 사양과 준비 체크리스트: `07_build_requirements/MODEL_SPEC.md`
- 모양 ↔ 모델 연결 정보: `src/data/shapes.json`
