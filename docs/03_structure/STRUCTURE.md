# Structure

> 최종 화면: Figma 구현 페이지 (1920 · 1024~860 · 모바일 859~375)

## Information Architecture
| Depth | Screen / 영역 | Key Elements |
|---|---|---|
| L0 | 글로벌 헤더 | 로고 FLORENCE FLOWER, HOME · BOUQUET · ABOUT · CONTACT (모바일: 햄버거 + 패널 열기 버튼) |
| L1 | 부케 빌더 (단일 화면) | 3D 캔버스 + 우측 설정 패널 + 하단 견적 패널 |
| L2 | 3D 캔버스 | 부케, 좌우 화살표, "드래그해서 360° 돌리기" 안내, VERSION(시안 1·2), 툴바(Undo · Redo · 앞 · 뒤 · 위 · 아래 · HAND) |
| L2 | 설정 패널 · I. FLOWER | REFERENCE IMAGE(업로드 · MY REFERENCE(S)), SHAPE OF BOUQUET, SIZE OF BOUQUET, COLOUR & FLOWERS(THEME · MAIN · SUB COLOUR, MAIN/SUB FLOWERS) |
| L2 | 설정 패널 · II. DRESS | DRESS IMAGE(업로드 · MY DRESS(ES)), SAMPLE DRESS(롱·미디·숏), LIGHTING(자연광·웨딩홀·스튜디오) |
| L2 | 견적 패널 (하단 고정) | 안내 문구, (예상) 금액, ASK TO FLORIST, DOWNLOAD IMAGE, CLEAR |

## 옵션 정의
| 항목 | 선택지 |
|---|---|
| 모양 | 라운드(둥글고 빽빽하게 모은 기본형) · 내추럴(줄기가 보이게 느슨하고 자연스럽게) · 캐스케이드(위는 풍성하고 아래로 폭포처럼 흘러내리는) · 크레센트(초승달처럼 한쪽 또는 양쪽으로 휘어지는) — 2026-11-18 4종으로 확정 |
| 크기 | 스몰 10~15송이 · 미디엄 16~25송이 · 라지 26송이 이상 |
| 테마 컬러 | 예: Blush Pink(핑크 계열 6종) + Ivory(아이보리 계열 4종) |
| 메인 꽃 예시 | 장미 줄리엣 1송이 6,500원~ · 백합 화이트 8,000원~ · 튤립 레드(판매 시즌 아님) |
| 샘플 드레스 | 롱(발목까지) · 미디(종아리까지) · 숏(무릎 위) |
| 조명 | 자연광 · 웨딩홀 · 스튜디오 (시안: 실내광 · 어두운 조명) |

## User Flow
| # | 사용자 행동 | 화면 반응 |
|---|---|---|
| 1 | 빌더 진입 | 기본 시안 3D 표시, "드래그해서 360° 돌리기" 안내 |
| 2 | (선택) 레퍼런스 사진 업로드 | MY REFERENCE(S)에 썸네일 추가, 최대 5장 |
| 3 | 모양 선택 | 꽃 수량·배치가 새 모양에 맞춰 바뀌고 가격 재계산 |
| 4 | 크기 선택 | 송이 수 변경, 가격 재계산 |
| 5 | 색 & 꽃 선택 | 테마 컬러에 맞는 꽃만 목록에 표시, 메인·서브 꽃 선택 |
| 6 | 3D 확인 | 드래그 회전, 앞·뒤·위·아래, HAND로 손에 든 모습 |
| 7 | II. DRESS 탭 | 드레스 사진 또는 샘플 드레스 선택, 조명 바꿔 보기 |
| 8 | 시안 비교 | VERSION에서 시안 1·2 전환 |
| 9 | 저장·전송 | DOWNLOAD IMAGE로 시안 저장 / ASK TO FLORIST로 플로리스트에게 보내기 |

## 화면 상태 정의
| 상태 | 언제 | 보여줄 것 | 다음 행동 |
|---|---|---|---|
| Default | 진입 | 기본 시안 + 기본 옵션 선택 | 옵션 고르기 |
| Section open/closed | 패널 섹션 헤더 탭 | 열림: 옵션 그리드 / 닫힘: 섹션명 + 현재 선택값 요약(예: "라운드", "장미 줄리엣 + 1") + 펼치기 아이콘 | 다시 열기 |
| Selected | 옵션 선택 | 검정 배경 + 크림 텍스트 | 다른 옵션 선택 |
| Unavailable | 판매 시즌이 아닌 꽃 | 비활성 + "판매 시즌이 아니에요" | 다른 꽃 선택 |
| Uploading | 사진 업로드 | 썸네일 위 어두운 덮개 + "올리는 중" + 진행 막대 | 대기 |
| Upload error | 용량·형식 초과, 실패 | 썸네일에 "다시 올리기" + 패널 안 오류 문구 | 다시 올리기 |
| Loading 3D | 첫 진입, 모양 변경 | 부케 실루엣 + 진행 막대 + "부케를 불러오고 있어요 · n%" | 대기 |
| Shape not ready | 3D가 없는 모양 | 옵션에 "준비 중" 태그 + 점선, 누르면 토스트 후 내추럴로 표시 | 다른 모양 선택 |
| No flowers | 고른 색의 꽃이 이번 주에 없음 | 점선 빈 상태 + "이번 주엔 이 색의 꽃이 없어요" | 비슷한 색 보기 |
| Clear confirm | CLEAR | 확인 모달 → 지운 뒤 "되돌리기" 토스트 | 모두 지우기 / 취소 |
| Send confirm · Sent | ASK TO FLORIST | 시안 요약 확인 모달 → 완료 모달 | 보내기 / 더 고칠게요 |
| Saved | DOWNLOAD IMAGE | "시안 이미지를 저장했어요" 토스트(3초) | — |
| Empty reference | 업로드 전 | 점선 + 아이콘 빈 칸 | 업로드 |
| Disabled | 되돌릴 것 없음 | Redo · CLEAR 회색(text-disabled) | — |
| Error | 3D 로드 실패 | 캔버스 가운데 메시지 박스 + "부케를 불러오지 못했어요" | 다시 시도 |
