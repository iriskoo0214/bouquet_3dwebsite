# UX Writing

## 톤앤매너
- 존댓말 **해요체**, 짧은 문장
- 꽃 이름을 몰라도 이해되는 말 (전문 용어 대신 "둥글고 빽빽한 기본형"처럼 생김새로 설명)
- 결과를 미리 알려준다: "~하면 ~돼요" (예: 모양을 바꾸면 가격도 다시 계산돼요)
- 가격은 단정하지 않는다: "(예상)", "~부터", "조금 달라질 수 있어요"
- 섹션 제목·주요 CTA는 **영문 대문자**(SHAPE OF BOUQUET, ASK TO FLORIST), 설명·옵션은 한국어

## 문구 목록 (최종 디자인)
| 위치 | 문구 |
|---|---|
| 캔버스 안내 | 드래그해서 360° 돌리기 |
| 툴바 | UNDO · REDO · 앞 · 뒤 · 위 · 아래 · HAND |
| 탭 | I. FLOWER · II. DRESS |
| 모양 안내 | 모양을 바꾸면 꽃 수량과 배치가 새 모양에 맞춰 바뀌고, 가격도 다시 계산돼요. |
| 크기 안내 | 꽃 크기에 따라 가격도 다시 계산돼요. |
| 색 안내 | 색을 바꾸면 그 색에 맞는 꽃만 보여요. 가격은 꽃 시세에 따라 조금 달라질 수 있어요. |
| 꽃 가격 | 1송이 6,500원부터~ |
| 품절 | 판매 시즌이 아니에요 |
| 드레스 사진 | 사진은 합성에만 쓰이고, 보낸 뒤 30일이 지나면 지워져요. |
| 샘플 드레스 | 사진이 없는 경우, 실제 드레스와 가장 비슷한 기장을 골라주세요. |
| 조명 | 조명에 따라 부케가 어떻게 보이는지 확인해 보세요. |
| 견적 | ⓘ 툴팁: 꽃 시세에 따라 조금 달라질 수 있어요 · (예상) 186,000원 / 적용 전엔 (예상) ~~186,000원~~ 192,000원 |

## CTA 규칙
| CTA | 위계 | 동작 |
|---|---|---|
| ASK TO FLORIST | Primary (검정 꽉 찬 버튼, 가로 전체) | 시안을 플로리스트에게 보내기 |
| APPLY CHANGES ⓝ | Primary — ASK TO FLORIST 자리에 대신 나타남 (Figma 285:1793) | 모양·크기·메인·서브 중 바뀐 묶음 수(ⓝ)를 3D에 반영. APPLYING → APPLIED(1.2초) → ASK TO FLORIST. 조명은 바로 반영 |
| DOWNLOAD IMAGE | Secondary (테두리 버튼 + 다운로드 아이콘) | 시안 이미지 저장 |
| CLEAR | Tertiary (텍스트) | 선택 초기화 — 실행 전 확인 필요 |
| UPLOAD IMAGE | Secondary (테두리, 가로 전체) | 사진 업로드 |

> 구현 페이지 문구 수정 필요 (2026-11-18 점검)
> - 로고 "FLORENCE FLOWEr" → **FLORENCE FLOWER**
> - 레퍼런스·드레스 이미지 아래 영문 안내문("Your image sits behind the drawing…")은 다른 서비스 문구 → FLOWER 탭: "마음에 드는 부케 사진을 올려 주세요. 꽃 이름은 몰라도 돼요." / DRESS 탭: "사진은 합성에만 쓰이고, 보낸 뒤 30일이 지나면 지워져요."
> - 크기 안내 "꽃 크기에 따라…" → **부케 크기에 따라 가격도 다시 계산돼요.**
> - DRESS 탭 LIGHTING 아래 "꽃 크기에 따라 가격도 다시 계산돼요." → **조명에 따라 부케가 어떻게 보이는지 확인해 보세요.**

## Error / Empty / Guide 문구
| 상황 | 문구 | 버튼 |
|---|---|---|
| 레퍼런스 영역 안내 | 마음에 드는 부케 사진을 올려 주세요. 꽃 이름은 몰라도 돼요 (기획안) | UPLOAD IMAGE |
| 업로드 제한 | JPG · PNG · HEIC / 최대 5장 / 한 장에 20MB까지 (기획안) | — |
| CLEAR 확인 | 고른 내용을 모두 지울까요? · 모양, 크기, 꽃, 올린 사진이 처음 상태로 돌아가요. 저장한 시안 이미지는 지워지지 않아요. | 모두 지우기 / 취소 |
| CLEAR 후 | 모두 지웠어요 | 되돌리기 |
| 3D 로딩 | 부케를 불러오고 있어요 · n% | — |
| 3D 로드 실패 | 부케를 불러오지 못했어요 · 인터넷 연결을 확인하고 다시 시도해 주세요. 고른 내용은 그대로 남아 있어요. | 다시 시도 |
| 모양 준비 중 | 이 모양은 3D를 준비하고 있어요. 지금은 내추럴로 보여드려요 (내추럴은 3D 준비 완료) | — |
| 업로드 실패 | 20MB가 넘는 사진은 올릴 수 없어요. JPG · PNG · HEIC 사진을 골라 주세요. | 다시 올리기 |
| 꽃 없음 | 이번 주엔 이 색의 꽃이 없어요 · 비슷한 색을 고르거나, 플로리스트에게 물어볼 수 있어요. | 비슷한 색 보기 |
| 보내기 전 확인 | 이 시안을 플로리스트에게 보낼까요? · 보낸 뒤에도 확정 전까지는 언제든 고칠 수 있어요. | 보내기 / 더 고칠게요 |
| 이미지 저장 | 시안 이미지를 저장했어요 | — |
| 전송 완료 | 플로리스트에게 시안을 보냈어요 · 플로리스트가 확인하면 카카오톡으로 알려드려요. 확정 전까지는 언제든 고칠 수 있어요. | 이미지 저장 / 확인 |
