## User Group
| 그룹 | 특성 | 사용 상황 |
|---|---|---|
| 촬영·야외 웨딩 신부 (주) | 개성 있는 부케를 원하지만 꽃 이름을 모름. 레퍼런스 사진과 색감으로 소통 | 플로리스트에게 직접 연락해 촬영 부케 주문 |
| 소형 꽃집 플로리스트 (보조) | 혼자 운영, 블로그·카톡 상담으로 바쁨. 꽃이 매주 바뀜 | 레퍼런스·손그림을 해석해 견적과 대체 꽃을 설명 |

## 가설 Persona
- **신부:** 30대 초반, 촬영 부케를 직접 주문하려 함
- 상황: 인스타·블로그에서 모은 부케 사진 여러 장을 섞어 보냄
- 목표: 내 드레스와 어울리는, 나다운 부케를 실패 없이 받기
- 불안: "사진이랑 다르게 오면 어떡하지", "이 크기면 풍성해 보일까", "얼마나 나올까"

## Key Behaviors
- 레퍼런스 사진에 원하는 부분만 동그라미 치고, 피하고 싶은 꽃과 비율을 따로 적는다
- 구도를 손으로 그려 보낸다
- 범용 AI로 드레스와 부케를 합성해 미리 가늠한다 (부케가 변형돼도 "느낌 잡기엔 좋았다")
- 견적·대체 꽃·변경 사항을 카톡으로 여러 번 주고받는다

## Pain Points
- **요청:** 원하는 스타일을 말로 설명하기 어렵다
- **소통:** 꽃 이름 대신 색감으로만 말해 같은 그림을 떠올리지 못한다
- **제작:** 꽃이 매주 바뀌어 사진과 똑같이 만들 수 없다 (장미 품종이 경매 당일 결정)
- **가격:** 사이즈·꽃마다 가격이 달라 매번 물어야 한다
- **결과:** 받기 전엔 확인할 수 없다 (사이즈업했는데 풍성하지 않음, 확정한 핫핑크 대신 다른 부케 도착)
- **기록:** 기록이 없어 업체와 플래너가 책임을 서로 넘긴다

## Needs & Goals
- 레퍼런스에서 출발해 원하는 부분만 고르고 바꿔볼 수 있어야 한다
- 똑같은 재현보다, 내 모습에서 어울리는 범위를 미리 맞춰야 한다
- 확정한 시안·가격·기한이 한곳에 남아 있어야 한다

## AI Interview Insights (플로리스트 인뎁스 인터뷰)
| # | 인사이트 | 근거(발화) |
|---|---|---|
| 1 | 문제는 제작 실력이 아니라 요청을 읽어낼 **단서의 부재** | "꽃을 모르셔서 대략 색감으로 지정을 많이 해 주세요" |
| 2 | '손님이 꽃을 모른다'의 본질은 **공통 언어의 부재** | "생각했던 색감이랑 다르다고 하시는 분도 있어요" |
| 3 | 사진 그대로 만들 수 없는 **구조적 한계** | "계절마다, 매주 꽃이 바뀌어서 사진과 똑같이는 못 해드려요" |
| 4 | 가장 많이 받는 문의는 **가격** | "사이즈랑 꽃마다 달라서 블로그에 가격을 안 적어놔요" |

## Journey Map Summary
| Step | Action | Pain Point | Opportunity |
|---|---|---|---|
| 레퍼런스 모으기 | 인스타·블로그에서 사진 수집 | 여러 장을 섞어도 원하는 걸 정확히 못 그림 | 사진을 올리면 색감·모양을 뽑아 시안 생성 |
| 원하는 모양 전하기 | 사진 6장 + 손그림 + 카톡 | 꽃 이름을 몰라 색감으로만 설명 | 보고 고르는 3D 단계형 빌더 |
| 꽃·가격 맞추기 | "이건 얼마예요?" 반복 | 꽃이 매주 바뀌고 가격이 제각각 | 이번 주 꽃 + 사이즈별 가격 범위 표시 |
| 어울리는지 확인 | 범용 AI로 드레스 합성 | 부케가 변형되고 실제로 만들 수 있는지 모름 | 드레스·조명과 함께 보기 |
| 시안 확정 | 카톡으로 재확인 | 기록이 없어 책임 공방 | 시안 이미지 = 주문서 |
| 완성본 받기 | 당일 확인 | 기대와 다른 부케 | 완성 사진과 시안 나란히 비교 |
